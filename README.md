# together-app-legal

Together iOS app 的隐私政策与服务条款公开发布版（GitHub Pages）。

**Source of truth** 在 [github.com/kb24123456/Together](https://github.com/kb24123456/Together) `docs/legal/`，
本 repo 是它的发布镜像，每次法律文档修订需要同步 push 到这里。

## URLs

- 首页：https://kb24123456.github.io/together-app-legal/
- 隐私政策：https://kb24123456.github.io/together-app-legal/privacy-policy/
- 服务条款：https://kb24123456.github.io/together-app-legal/terms-of-service/

## 维护

修订流程在 main repo `docs/legal/README.md`。简而言之：改 main repo 的 .md →
拷贝过来 → push → GitHub Pages 自动 rebuild。
